# AppTS Full-System Mockup

This directory is a synthetic, non-production, browser-first product mockup for the AppTS rebaseline.

## Purpose
- Make AppTS tangible before deeper implementation work.
- Show the full-system envelope instead of a minimum-requirements fragment.
- Preserve the human-facing grammar: see → understand → decide → act → observe consequence.
- Demonstrate one human holding multiple valid capacities without making manual Role switching the normal product interaction.
- Provide an interactive functional block diagram and synthetic end-to-end scenario lab.

## Important
- No real customer data.
- No production actions.
- All state changes are simulated in the browser.
- Raw diagnostic JSON is deliberately not the primary human interface.
- Existing runtime/engine remains untouched.

## Public mockup
Deployment workflow serves this directory on the existing cloud server at port 8088.
